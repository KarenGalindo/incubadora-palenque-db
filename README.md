# 🧾 Base de Datos - Incubadora El Palenque

## 📌 Descripción
Este proyecto contiene el diseño e implementación de una base de datos relacional desarrollada en MySQL Workbench.

## 🧩 Estructura
- Usuario
- Cliente
- Producto
- Proveedor
- Venta
- DetalleVenta
- Inventario

## ⚙️ Tecnologías
- MySQL
- MySQL Workbench

## 🚀 Cómo ejecutar
1. Ejecutar script.sql
2. Ejecutar inserts.sql
3. Ejecutar consultas.sql
